## Backlog-runde september — 19 saker på staging

**Tilgang og medlemmer**
• **Flere roller per medlem (#48)** — en person kan være Musiker + Styremedlem samtidig; tilgangen er summen. Prøv «Roller…» i Medlemmer og «Hva rollene gir» i Innstillinger.
• **Medlemsprofil (#14, #25)** — telefon/e-post er nå synlig for alle aktive medlemmer i Medlemmer (klikkbart). Bistemmer og interesser (rigg, transport, dugnad …) settes på Min profil, og kan filtreres på i lista.
• **Dele stemmen din (#16)** — på Mine noter kan du la et annet medlem lese én av stemmene dine (kun lesing, kan fjernes av begge).

**Prosjekter**
• **Prosjektsiden er blitt et dashboard (#9, #10, #29)** — tidsplan (konsertstart, oppmøte rigg/lasting, hvem kjører), koblede øvinger med praktisk info (sted, kart, oppmøtetider, dirigent, nøkkelansvarlig), repertoar, slagverk.
• **Solister, slagverksliste og øvingsstatus (#50, #34, #30)** — solister per stykke i prosjektet, gjenbrukbar slagverksliste per verk med samlet behov, og frivillig «øves på / vil øve med noen» per stykke.
• **Prosjektvarsling og spørsmål (#18, #51, #27)** — ved publisering kan prosjektansvarlig sende e-post (av som standard), og senere ett samlet oppdateringsvarsel. Medlemmer kan stille spørsmål på prosjektsiden; ansvarlig svarer og markerer avklart. Eget varslingsvalg på Min profil.
• **Riggeliste og sceneoppsett (#12, #11)** — «ta med»-liste per prosjekt/øving med «tatt med» / «kommet tilbake», og grafisk sceneoppsett (stoler, stativ, slagverk) som kan lastes ned som SVG.

**Beskjeder**
• **Målretting og sett-status (#28)** — en beskjed kan gå til bestemte stemmegrupper eller et prosjekt; forfatter/styret ser «sett av N av M», med navneliste for viktige beskjeder. Merk: «prosjektmedlemmer» = de som har svart kommer/usikker på en koblet øving pluss ansvarlige i tidsplanen.

**Nye områder (kort på forsiden)**
• **Utstyr (#13)** — register over instrumenter og utstyr med bilde, eier, lån og prosjektkobling. Styret kan redigere, alle kan se.
• **Media (#32)** — opptak, bilder og video med avspilling og spoling. Maks 95 MB per fil foreløpig.
• **Sosiale arrangement (#31)** — alle kan opprette pub/julebord/tur i Kalender, med påmelding, frist, maks antall og venteliste.

**Verdt å teste spesielt:** rolle-endringer (logg inn på nytt etterpå), at kontaktinfo vises riktig, e-post fra prosjektpublisering (all staging-e-post går til Sindre), og sceneoppsettet på mobil.
